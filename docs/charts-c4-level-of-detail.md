# Charts C4-03：保真抽样和层级细节

执行完成日期：2026-10-19。最终候选 `c4-level-of-detail-source-v1` 已通过 Windows 与 Ubuntu26.04 WSL2/WSLg 软件验证。新增显式线性折线 MinMax，保留峰谷、映射/补值后仍非有限的断点和交互数据身份；默认沿用 C4-02 的原始细节/可见裁剪路径。Demo 已提供模式、像素宽度及缩放对比。下一项为 C4-04 高效命中，完整 C4 性能、资源预算和物理平台资格继续开放。

## 实现与数据身份

- LineSeries 新增 SamplingMode=None/MinMax，默认 None，沿用 C4-02 的原始细节/可见裁剪路径；SamplingPixelWidth 为每桶 1～64 物理像素，默认1。显式 MinMax 只减少显示几何，不改 ItemsSource、不可变坐标/元数据快照、SourceIndex、StableId、Item 或 RawPoint。
- 按不可变坐标所有者复用分块极值层级，在物理屏幕像素桶内保留首点、末点、最小 Y 和最大 Y，按原物理序号输出；极值并列取最早原始序号。缩放、平移、轴方向和 DPI 变化重新选择合适屏幕桶，数据层级继续复用。屏幕密度以 TopLevel.RenderScaling 为准，导出以统一布局比例为准；任意祖先 RenderTransform/Viewbox 的缩放/旋转尚未纳入密度资格。
- 分段跟随既有 EmptyPointMode 映射/补值后的坐标：仍非有限时保留断点，Zero/Average/Interpolate 等已经补成有限值时沿用原有连续语义；legacy 线中带 IsEmpty 但坐标有限的点仍按既有规则绘制。每个有效有限连续段独立抽样，有意抽掉的点保持同一 figure，不因序号跳跃错误断开。查询保留范围前后原始邻点及没有中心点时穿越边界的相邻两端。
- 桶边界使用实际折线原有前向投影算术；数值快速路径与一般路径不混用，保留数值端点与 FMA 语义。查询范围按描边 miter 和抗锯齿裕量扩张（5×约束描边厚度+max(1,1/输出比例) DIP，抗锯齿至少保留1物理像素），随后仍使用原绘图裁剪。
- GetSamplingInfo 在 UI 线程返回当前模式、是否应用、源/候选/绘制顶点数、连续段、物理桶预算、DPI 比率及回退原因；VisibleCount 含边界所需邻点，PixelBucketCount 是整个受保护绘图区的桶预算，并非每连续段实际占用桶总数。
- 非有序 X、平滑/阶梯、堆叠、标记/标签、空间画刷、轴断裂、无效域、未知投影或投影饱和等路径保守使用原几何并给出明确原因。未将柱状/散点密度聚合伪装成无损原始项绘制。
- Tooltip、点命中与点/矩形选择继续查询完整原始数据；测试刻意命中未被绘制的原始点，并独立检查 RawPoint、源序号、稳定身份及 Item 引用。抽样索引不替代交互原始数据索引。
- 导出默认使用原始折线几何，ChartExportOptions.UseSampling 显式开启时按目标输出像素比例重新选择桶；不同尺寸/DPI 不复用屏幕桶结果，取消不会发布部分抽样计划。
- Demo 提供密集峰谷/间隙折线、原始与 MinMax、像素宽度切换和缩放/重置，展示原始候选与绘制顶点计数并保留原始交互。
- 独立诊断分开记录冷源映射/层级构建与10次预热后稠密视口变化；原始扫描 oracle 在计数区间之后重新计算每连续段、每物理桶的首末峰谷及邻点，比较完整原始序号/figure 起点集合与 SHA。计时和线程分配仅作诊断，非 FPS、present、正式延迟或长期内存 SLA。完整序号对照的是新反射 sampler 查询，并非单独截取实际 renderer 的序号数组；共用 planner/map/保护边界的渲染集成另由源码审阅及原生峰谷/间隙/导出 PNG 覆盖。

## 剩余问题

- 下一项 C4-04 高效命中：百万点 hit p95 历史回退 0.7649→1.1235 ms 按用户决定保留后续专项；本批保留原始交互身份，不声称完成高效点/线段查询资格。
- MinMax 只对明确适用的单调线性折线减少几何；非有序数据、平滑/阶梯/堆叠、面积/范围、标记/标签、空间画刷及独立图族保守使用原数据。柱状/散点密度聚合尚无公开聚合语义或质量声明，未实现。
- 极端断点数可令每连续段必留点和占用桶总数接近 N；无损保留首末峰谷并不保证所有数据 O(像素宽度)。图像与原始折线逐像素相同不是 MinMax 契约，官方性能比较须使用相同可比较画质与采样配置。
- 首次源映射、极值/层级及空间索引仍可能扫描全量；每数据层级保留分块索引数组，当前窗口结果按视图缓存。缓存字节预算、原生/GPU资源、异常回收及30分钟/8小时长稳仍留 C4-05～C4-08。
- 类别组距 LayoutCategoryGroups 的全局间距计算、编码排序及不适用系列候选仍有与 N/K 对应的成本；未取得全部图族 O(visible) 或 O(1) 绘制资格。
- Windows 合成原生窗口、Headless 包消费者与 Ubuntu26.04 WSL2/WSLg 软件验证不代表物理 Windows/Linux、原生 Wayland、国产 Linux、多屏 DPI、真实触摸/触控板/读屏器或 backend/GPU/compositor present 资格。
- 完整 C2/C3/C4/C7、C5/C6 图族、官方许可运行时功能/默认值/API/二进制等价继续开放；既有图族标签/模板/交互限制不被抽样关闭。
- Windows UIA/Linux AT-SPI 原生选中集合枚举继续留用户延期的 A11Y-NATIVE-01；AX06 标题/末刻度和四份历史 PixelProbe DLL 证据缺口原样保留。
