# Charts C4-01：数据与视图分层失效

执行日期：2026-10-18。最终候选 `c4-layered-invalidation-source-v1` 已通过 Windows 与 Ubuntu 26.04 WSL2/WSLg 软件验证。下一项为 C4-02 可见数据裁剪。当前验证范围为 CartesianChart 主数据管线与内置系列；独立图族保留各自现有缓存，完整 C4 性能、内存长期稳定和物理平台门槛继续开放。

## 实现与失效边界

- 数据准备与视图分开：挂载的 CartesianChart 按数据/配置版本复用源快照、分类映射、比较/堆叠/范围覆盖及点编码结果；布局/视口变更通过小型视图包装复用同一不可变数据，数据或映射/拓扑变化再重建。未挂载及未知扩展按原语义保守刷新。 标题/图例、字体和安全的纯绘制配置保留数据层；影响点编码默认颜色/大小的配置仍保守重建对应显示样式，RawPoint 使用 O(1) 覆盖共享数值拥有者。
- 极值摘要按不可变快照弱关联缓存，数值范围与合法域扫描独立于 X/Y 命中索引；X/Y 排序索引按需首次查询构建并复用。基础尺度与类别标签独立于视口；类别标签首次防御性复制后由内部不可变所有者复用。
- 轴文字与绘图按各自身份/视图失效：Tooltip/十字线/选择重绘不清除轴文字或数据层；视口改变仍重新计算必要刻度/布局与投影。系列绘图复用内置几何/原语，交互叠加在当前场景上独立绘制。 绘制式 Tooltip 通过最多32项的 FIFO 缓存复用文字/度量，按内容、字体、文化与画刷等键复用；formatter 每次继续调用，相同命中点移动锚点只更新位置，不重建文字，不把不同数据点的内容变化误作失效失败。轴文字容量保持有界 FIFO，避免字典槽位复用造成新文字反复被逐出。
- 内置系列记录并重放原本原语，保留 DrawLine/DrawRect/DrawEllipse/DrawGeometry 的光栅语义；动态选择透明度、裁剪与当前笔刷在当前绘制上下文生效。自定义 renderer 继续每帧调用，不强加未声明的外部状态版本协议。
- 点编码视图复用一次绘制排序和按需投影命中结构；线段插值/Trackball 复用当前视图的投影顶点及断裂切分数据，数据或视图变化后重建。外部可变自定义投影保留保守实时路径。 线性线段查询仍逐个检查已缓存的投影顶点，复杂重叠点的候选命中仍可能为 O(N)；本批减少源访问和重建，不承诺这些查询变为 O(log N)。 已知内置轴变换可复用；非单调自定义分类轴查询按完整候选回退，未知自定义投影实时求值。自定义轴的域或配置变更必须按既有 Changed/Refresh 协议通知，未声明裸字段变化不自动构成新版本。
- 缓存只持有当前必要数据/场景；换源、配置变化及卸载解除旧层引用，弱关联快照/上下文缓存不反向强保留退休数据。动画、导出、原地可变几何的 Refresh 约定与扩展回调的重入安全继续由现有契约和回归覆盖。
- 新增独立缓存机制诊断入口：9 场景每场景1次冷查询、30次预热与100次 Tooltip 更新+DrawingGroup Render，逐项记录源枚举/访问、数据/极值/视图/文字/几何/排序命中/线段/标签复制计数；按原始公式核对来源身份并记录原始计时与线程分配。门禁由操作数和语义决定，不设置机器相关延迟阈值。 另对同一命中点执行50次小幅锚点移动，要求交互文字构建为0、复用次数至少50；不同命中点的文字构建不设零增量要求。

## 缓存机制与诊断测量

## 剩余问题

- C4-02 可见数据裁剪为下一项，仍需完整视口边界邻点/形状穿越语义、LOD、增量更新、实时调度及多图预算；现有缓存复用不等于完成完整 C4。
- 保留绘图重放仍随绘图操作数增长，密集散点/重复符号/曲线仍有 CPU 与线程分配成本；极端重叠点命中候选和线性插值查询缓存顶点仍有 O(N) 最坏路径。后续优化必须保留命中、画质与来源身份；没有 O(1) 绘制或 present 保证。
- 本批计时与线程分配为 Headless 程序化诊断，不认证正式 FPS/尾延迟/内存字节预算或长稳 SLA。百万点命中 p95 历史回退 0.7649→1.1235 ms 继续留 C4 后续优化。
- 缓存资源字节上限、原生/GPU retained resources、在途任务及30分钟/8小时内存稳定性仍需专项；当前换源/卸载引用释放回归不能替代完整内存资格。
- 自定义 renderer/轴/投影可能依赖外部可变状态，继续按其既有通知协议和保守刷新路径执行；裸字段变化仍需 Changed/Refresh，不保证未知扩展的无通知拓扑/域变更被自动发现。独立 Circular/Polar/Gauge/Sparkline/Analysis 图族保持各自缓存，未取得本批全族分层缓存或性能资格。
- C3-01～C3-07 和完整 C2 的已记录图族/模板/标签/动画/联动适配残余继续开放；未使用许可官方运行时作性能、视觉、API 或二进制等价对照。
- Windows 与 Linux 证据限原生合成窗口、Headless 与 Ubuntu 26.04 WSL2/WSLg；物理输入、实体 Linux、实际 backend/GPU/compositor present 与正式平台门槛未认证。
- Windows UIA/Linux AT-SPI 原生选中项枚举继续由用户延期到 A11Y-NATIVE-01，完整原生桥接门槛未关闭；AX06 标题/末刻度布局及四份历史 PixelProbe DLL 证据缺口保留。
- 轴标题/文字等部分视图样式变化仍保守重新生成基础尺度，但复用快照极值且不重新遍历源；后续可进一步缩小尺度/文字失效键。
- 编码点的绘制排序缓存当前属于 ChartSeriesRenderContext 视图；视口刷新创建新上下文时，SizeAscending/SizeDescending 仍可能重新执行 O(N log N) 排序。源快照、极值和坐标 X/Y 索引可跨视口复用，绘制排序更细粒度复用留后续。
