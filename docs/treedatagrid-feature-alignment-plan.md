1. 补齐列级配置、列头显隐、选择拦截、单元格事件与元素工厂等公开能力。
2. 扩展绑定自动写回和行拖放，保留现有身份、草稿、事务及回调重入规则。
3. 完成新增功能与已有功能的组合验证，并补齐真实平台验收证据。
4. 将异步加载和业务增强单独排期，不把未经核实的能力称为官方差距。

当前工程依赖以 Directory.Packages.props 和锁文件为准；已记录的参考基线为 Avalonia 12.0.3 / .NET 10。本轮不附带升级依赖、修改产品版本或发布 NuGet。公开 API 以新增兼容入口为主，不为了名称一致直接删除旧成员或替换枚举。

## A2：选择拦截和单元格事件

当前 A2.1–A2.2 已完成。新增 SelectionChanging / SelectionChangeCompleted 和 CellPrepared / CellClearing / CellValueChanged，全部主动选择入口接入事务并保留旧事件签名。Core138 / Headless240 / Themes27 共 405 项、两类独立包消费、原生 136/29/36 项及图库导航测试通过；取消、强制清理、异常和离屏通知边界见 [A2 完成验收](treedatagrid-alignment-a2-status.md)。

### A2.1 可取消的 SelectionChanging

- 在状态层建立选择事务，控件转发事件；覆盖鼠标、键盘、SelectedItem/SelectedIndex、程序选择和自动化 provider。
- 事件提供变更原因、旧/拟议选择及当前单元格信息。多选快照避免把整个数据源物化；矩形选区保留现有表示方式。
- 推荐顺序：计算拟议选择并允许取消 → 提交必要的旧编辑 → 重新验证 Source/版本/目标 → 一次性应用选择和发送完成通知。
- 取消或编辑校验失败时，选择、锚点和当前单元格保持原状，不执行滚动到新目标等后续动作。编辑已经成功提交后，不能承诺回滚任意业务 setter。
- 模型删除、换源和隐藏列导致的强制状态清理不可由取消事件保留无效身份；这些路径须与用户主动选择区分并发送明确通知。
- 批量选择只发一次逻辑变更，重入必须拒绝或受控排队，不能递归应用半完成状态。取消 MVVM 赋值后，公开属性和实际状态保持一致。

### A2.2 单元格生命周期与值变更事件

- 增加 CellPrepared、CellClearing：分别在身份/绑定建立后、解绑和回收前通知，携带 NodeId、ColumnId、源路径及当前显示位置。
- 增加 CellValueChanged：覆盖成功编辑提交和可观察的模型更新；定义旧值/新值可用条件以及 ChangeReason。
- 不因容器首次创建或滚动回收而误报模型值变化；同一次写回触发 INPC 时避免重复通知。
- 明确通知边界：能追踪的源模型/绑定通知以及显式 Refresh 可以产生更新；无通知对象的任意内存赋值不能自动检测。离屏单元格是否通知必须形成支持表，不能仅凭可见控件变化宣称全量支持。
- 回调内换源、删除目标、隐藏列、换主题或异常，不能造成重复清理、订阅泄漏、错误身份通知。

验收：取消前后状态快照一致；鼠标/键盘/MVVM/provider 路径一致；行列双向虚拟化下事件成对且身份正确；值变化通知不重复，通知边界有测试和文档。

| A3.4 | 复杂绑定支持矩阵 | 逐项评估 ElementName、RelativeSource、显式 Source、索引器和值类型中间路径；可安全捕获/验证目标的路径纳入支持，其余给出诊断和显式 writer 示例 |

转换与提交顺序固定为：读取草稿 → 转换为模型值 → 验证 → 检查原编辑目标仍有效 → 调用一次 writer。取消不调用 writer；转换/验证失败保留草稿。展示用 StringFormat 不自动视为可逆转换。

开始编辑后，中间对象、绑定、外部源或索引器目标更换时，拒绝把旧草稿写到新对象。程序化值变更与 A2 的 CellValueChanged 协作去重。

若当前公开 API 无法满足安全写回，先形成可复现原型和技术结论，再评估依赖升级或受支持的绑定适配器；不能使用私有反射绕过，也不能把显式 setter 路径记为“任意绑定自动写回完成”。该项作为未完成能力继续跟踪，重估后续工作量。

验收：实际编译 XAML 消费；成功、取消、转换错误、验证失败、目标更换、回收、换源均有针对用例；更新[绑定支持表](treedatagrid-binding-support.md)，分别列明自动支持、显式 writer、未支持三种状态。

## A4：拖放事件与行移动能力

当前 A4.1–A4.3 已完成本地实施与范围验收，基于 A3 已交付的受控范围推进，不依赖其未完成的通用编译绑定扩展。新增路由拖放事件、整行拖动配置、ItemsSource 原集合适配和多节点原子移动，保留旧单节点事件。Core149 / Headless298 / Themes29 共 476 项、两类独立包消费（纯功能42项）、原生152/29/36项和图库导航通过，见 [A4 验收记录](treedatagrid-alignment-a4-status.md)及[移动支持表](treedatagrid-row-move-support.md)。物理拖动仍按 A6 验收。

### A4.1 对外拖放生命周期

- 增加 RowDragStarted、RowDragOver、RowDrop 对应能力，固定路由方式、取消/Handled、落点与允许效果的语义。
- 事件携带源、节点身份、目标身份和 Before/After/Inside 位置；拖动悬停与实际模型提交分离。
- 保留 RowMoveRequested/Completed 作为受控模型移动入口，同一次操作不得被新旧事件处理两次。
- 扩展可拖动区域配置，默认保留行号列启动，业务可选择整行非交互区域；TextBox、按钮、选择拖动及列调宽不被抢占。
- 默认操作仍为同表 Move。跨控件、外部载荷及 Copy/Link 单独列为增强，不因新增事件就宣称已支持。

### A4.2 ItemsSource 与集合适配

- 为 ItemsSource 擦除适配器补明确的移动能力协议，把源位置映射回原集合。
- 优先支持有可靠 Move 语义的同父集合；跨父移动继续要求事务适配器或明确的应用处理器。
- 不依据 IList.IsReadOnly=false 推断跨集合写入可原子提交。失败补偿、提交后观察者异常和真正未提交必须能区分。
- 排序/过滤期间保留默认拒绝策略，提供应用映射源位置的事件示例。不要将视图行号直接作为源集合下标。

### A4.3 多节点移动

- 在已选行发起拖动时支持受控批量移动，保留源顺序；选中祖先与后代时去除冗余后代。
- 校验所有节点和落点后一次提交；先支持同父批量移动，再支持事务集合间的跨父批量移动。
- 同父移动保留身份；跨父移动根据返回身份映射恢复选择/当前项，不承诺旧 NodeId 不变。
- 无事务保证的集合拒绝默认批量移动，不允许部分成功后仍报告普通失败。

验收：上下移动的索引修正、重复模型的不同出现位置、选中祖先/后代、源变更、编辑失败、只读集合、树循环、Esc/捕获丢失、自动滚动、悬停展开和回调抛错。多选移动属于本轮交互增强，官方同等行为仍须单独核对。

## A5：可替换元素工厂

当前已完成公开三角色工厂、按表格/会话隔离的池与 Release、运行时切换和错误/重入处理。返回既有 sealed 标准宿主，通过模板、属性和寿命扩展；不支持任意 Control 替换内部协议。新增 25 项、共 501 项控件测试通过，默认路径同机微基准未见明显退化。完整时序及责任见[工厂契约](treedatagrid-element-factory.md)，独立消费与性能的验收边界见 [A5 记录](treedatagrid-alignment-a5-status.md)。

- 提供公开 ElementFactory 或等效接口，覆盖行、单元格和列头的创建、准备、清理、回收。
- 默认工厂保留当前 presenter 与池化行为；工厂不是主题替代品，功能包继续不依赖主题包。
- 定义工厂所属控件、回收池所属工厂和兼容类型规则；不同工厂产物不得混用同一回收池。
- 运行时更换工厂时清理旧容器、解除订阅并重新实现可见内容；逻辑选择与草稿仍绑定 NodeId/ColumnId。
- 与 A2 的生命周期事件保持唯一调用顺序；自定义元素仍须提供必要的输入、焦点、编辑器及自动化语义。

验收：自定义工厂示例可通过纯功能包消费；错误返回有诊断；换工厂/换主题/换源后无残留订阅；创建数受视口约束，布局与滚动相对当前基线无无法解释的退化。

## 每阶段完成标准

1. 公共契约、实现、默认主题、自定义模板影响、Demo 和说明同时交付。
2. 测试重点覆盖目标身份、取消零写回、事件去重、重入与回收，不为简单属性复制实现式测试。
3. 执行适合变更的 Core、Headless、Themes 回归；阶段集成运行 scripts/Verify.ps1。脚本范围可能随仓库变化，执行前检查，不修改通过条件来掩盖失败。
4. 涉及交互时运行 TreeDataGrid 原生检查；程序化输入与离屏图不能代替真实 IME、物理拖动或读屏。
5. 更新 public-api.txt、使用说明、绑定支持表、必要的模板契约及迁移说明，保留旧 API/消费者回归。
6. 状态按“未开始、实现中、自动验证完成、平台验证完成、受环境限制”记录；不以测试数量替代完成判断。
