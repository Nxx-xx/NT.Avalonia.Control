# Charts C2-08：JPEG 与异步导出

执行日期：2026-10-17。范围为现有折线、柱状、散点及共用场景的 JPEG、PNG/JPEG 异步导出，补齐尺寸、背景、DPI、取消、失败与 Demo/Usage。最终 v2 已从同一冻结源码在 Windows 与 Ubuntu 26.04 WSL2/WSLg 完成下列功能验证；C2 整阶段、物理桌面资格及 C4 性能出口保持开放。

## 实现和使用

- 保留 `TryExportPng(Stream|string, ChartExportOptions?)`；新增同步 `TryExportJpeg`，以及带 `CancellationToken` 的 `TryExportPngAsync` / `TryExportJpegAsync`，均有流和文件路径重载。异步方法返回 `Task<bool>`。
- `ChartExportOptions` 复用 `PixelSize`、`Dpi`、`Background`、`MaximumPixelCount`，新增 `JpegQuality`（默认 90，1–100，仅 JPEG 校验）。布局沿用当前已安排的图表，等比缩放、居中；不会按导出尺寸重新布局图例或标签。显式像素尺寸下 DPI 仅改变元数据；省略尺寸时按 `ceil(Bounds × DPI / 96)` 推导。
- DPI 允许 0.1–9600；单边上限 32768，默认像素预算 16777216，可配置上限 67108864。编码输出继续有字节预算。PNG 写入 pHYs；JPEG 同时写入整数 JFIF density 和保留五位小数的 EXIF rational X/YResolution、英寸单位。读取器对小数 DPI 的展示由其元数据支持决定。
- PNG 保留透明画布。JPEG 从白色画布开始，再合成选项背景、图表背景与内容，因此半透明背景也得到不透明输出。背景选项不会自动重设轴、标题或标签的前景色；深色主题的浅色文字搭配白底/浅底可能低对比，应用应同时选择匹配的前景与背景。同步和异步使用相同的导出投影，包含当前轴、缩放、多轴标注、参考元素、图例/标签及控件内容。
- 同步接口要求 UI 线程。异步允许后台调用，在 UI 线程捕获一次当前画面和独立 RGBA 像素数组，释放平台位图后在工作线程编码和分块写入。后续数据/视图变化不会改变已捕获的快照；捕获不会推进动画时间线，暂停动画帧可直接导出。
- 每图表同一时间允许一个导出，重入/并发调用直接失败，不排队积累多个大图快照。普通失败返回 false，并在 UI 线程触发一次 `ExportFailed`；失败事件处理器自身抛出的异常继续向调用方传播，导出占用仍会释放。
- 已取消的令牌在校验和捕获前抛出 `OperationCanceledException`，不触发 `ExportFailed`。排队等待 UI 捕获可取消；捕获/单次压缩属于不可抢占阶段，在阶段前后检查取消；写入各块传递令牌。取消不保证正在执行的压缩立即停止，也不能中断忽略令牌的调用方流。
- 调用方拥有流，库不关闭流。流失败或中途取消可能留下部分字节，由调用方决定回滚/销毁。文件导出写同目录临时文件，完成并检查取消后替换目标；失败或最后一次令牌检查时已观测到的取消保留旧文件，并尽力清理临时文件。随后启动的原子替换为提交点，提交后到达的取消不回滚已完成文件；进程崩溃、外部锁定/权限变化导致的清理失败不在保证范围内。

```csharp
var options = new ChartExportOptions
{
    PixelSize = new PixelSize(1200, 700),
    Dpi = 144,
    Background = Brushes.White,
    JpegQuality = 90
};
try
{
    bool saved = await chart.TryExportJpegAsync(path, options, cancellationToken);
    // false 的具体原因由 chart.ExportFailed 提供。
}
catch (OperationCanceledException)
{
    // 用户取消；文件提交前保留原目标。
}
```

Demo → Charts → **“导出：PNG、JPEG 与异步取消”** 可选择格式、像素尺寸、DPI、背景、质量，执行同步/异步导出、本地保存、取消和失败示例，并展示缩放和暂停动画帧。原生 smoke 的 **“导出完整性证据”** 同时产生亮暗主题图片、元数据、失败/取消和实际文件保留证据。

## 编码依赖与兼容性

Avalonia 12.0.3 本地 Skia 的两个 Bitmap.Save 重载实际均走 PNG，不能通过扩展名得到 JPEG。本批引入纯托管 `StbImageWriteSharp 1.16.7`，无传递依赖及新增平台原生包。固定 NuGet 包和上游提交身份记录于本批 `dependency-stbimagewritesharp-v1.json`；上游移植项目 README/csproj 标示 Public Domain，NuGet 归档未声明 SPDX license expression/file。功能包包含 [THIRD-PARTY-NOTICES.md](../src/NT.AvaloniaControl.Charts/THIRD-PARTY-NOTICES.md)，保留该区别以及固定来源和归档哈希。

同步 PNG 保留既有平台编码路径。异步 PNG/JPEG 对捕获的非预乘 RGBA 编码。透明/抗锯齿位置在预乘与非预乘整数换算中，旧同步 PNG 与异步 PNG 可出现 RGB 最大 1/255、Alpha 完全相同的量化差异。因此不宣称跨这两条编码路径逐字节或逐像素完全一致。同一路径的同帧/显式尺寸跨 DPI、以及不透明背景的同步/异步 PNG 保持精确像素比较；JPEG 以独立解码、元数据和有损误差比较验收。

## 剩余问题

- 取消是分阶段协作式取消；UI 捕获和单次编码耗时仍可能影响响应。每图一个导出不限制不同图表并发，像素预算不是整个进程峰值内存预算。导出吞吐、峰值内存、长稳、压力/慢流及编码阶段响应时间仍待 C4 专项测量，本批无正式 SLA 或性能回归通过结论。
- JPEG 为有损格式，色度抽样和量化可改变细色边、小字附近的颜色，即使默认质量 90 也不保证小 ROI 内保留 PNG 的精确原色；质量 40 的细节损失更明显。当前只公开质量选项，不单独控制色度抽样。需要无损像素保真时可选择 PNG；指定导出背景也不会自动替换主题前景色。
- 双平台物理保存对话框交互/取消、真实设备/DPI/多屏、Ubuntu 22.04/24.04 物理桌面、原生 Wayland/ARM、GPU/backend/present、UIA/AT-SPI 和官方许可运行对照保持开放。WSLg 合成窗口不替代上述资格。
- C2-09 点级辅助语义待推进；高级标签避让、类别图例、范围概览、跨图游标、四界 Viewport 内独立 nullable-auto 轴和未来图族仍开放。
- C2-07 的逐系列独立时序/进度、离场/错峰、额外几何、系统 ReduceMotion 自动桥接及静止指针跟随动态 Tooltip/Trackball 读数继续开放。AX06 多轴角落标题/末端刻度轻微重叠保留既有记录。
- C4 百万点命中 p95 的 0.7649→1.1235 ms、历史残余、增量/LOD、内存与长稳按用户决定后期处理；本批不重写或关闭旧性能门禁。
- 继承的 4 个原始 v15 BarCache.PixelProbe.dll 缺失（8 处历史引用）继续保留，不用重建产物替代。C0、v15、C2-03 至 C2-07 原报告/API 保持原身份。
