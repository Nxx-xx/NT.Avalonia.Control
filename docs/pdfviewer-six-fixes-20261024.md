## 行为与资源约束

- 书签仍不进入内容撤销历史。清理后的 Undo 不重新带回书签，缺少已保存书签时必须保持脏状态。
- 书签比较使用现有 API 的有序集合语义；重复设置当前集合仍为 no-op。
- 成功打开、新来源、关闭或释放会清理密码重试输入；只隐藏提示仍按旧契约保留它。加载器不关闭调用方原流。
- 可寻址流只分配一个精确长度输入缓冲，非寻址 / 超大流沿用文件暂存；没有改回整文件 MemoryStream 双份复制。
- 文件保存失败仍不移动保存点；现有事务失败回滚、历史预算、取消和释放回归继续执行。

## 失败记录与退出范围

首轮文件保存回归在沙箱临时目录移动时被拒绝，测试输出改放工作区后通过；旧记录保留。初轮完整 Core 出现一次既有资源采样正值断言失败，定向检查及最终完整复跑通过，没有修改采样实现或降低断言。导航版本检查初版使拟合自身的缩放更新失效，既有用例捕获后修正并重跑通过。

本轮包消费使用经过归档哈希及载荷核验的离线依赖源、独立空缓存，任务级 `NuGetAudit=false`；未改项目 / CI 审计设置，也不宣称新的漏洞审计通过。
