# Charts C2：图例与数据标签控件模板

更新日期：2026-10-16。本批继续 C2-01/C2-02，完成现有折线、柱状和散点图的图例模板、图例纵向滚动及数据标签模板，并接入 Demo、编译绑定 Usage 和真实包消费者。C2 整阶段继续开放。

按用户决定，百万点命中尾延迟移到后期 C4 优化。v15 的独立 hit p95 `0.7649→1.1235 ms` 继续作为未解决的历史实测保留；本批没有重跑百万点时序池、内存回归或正式性能门槛。此前的 100/100 目标门禁和 1896 对像素结果只适用于 [v15 源码与产物](charts-tail-latency-validation.json)。

## 已实现

| 接口 | 行为 |
| --- | --- |
| `CartesianChart.LegendItemTemplate` | 实际 Avalonia 控件，绑定 `ChartLegendItem`；同一系列/模板复用，保留原 Series、颜色、可见状态与可见裁剪 Bounds。 |
| `IsLegendScrollable` | 在有界区域纵向滚动；支持原有四边、横排换行/竖排、浮动和停靠。滚动后的点击仍经过可取消的 `LegendItemInvoked`。 |
| `LegendMaxWidth` / `LegendMaxHeight` | 可选 DIP 上限；单独配置也启用有界默认条目。未启用控件模板、滚动或尺寸限制时保留原绘制路径；浮动图例与控件标签组合时复用图例宿主以保证层级。 |
| `ChartSeries.DataLabelTemplate` | 绑定 `ChartDataLabelContext`；保留 `Data.Item/Point/SourceIndex/StableId`、图表局部 DIP 锚点和格式化轴值；`Text` 为 formatter/default 输出。 |
| 标签布局 | 沿用候选预算、位置、偏移、避让、正负柱和断轴/绘图区裁剪；每系列默认最多 500 个候选，不为视口外/无效锚点创建 UI 控件。 |
| 生命周期与输出 | 继承资源、编译绑定和业务 INPC；切换模板、隐藏/删除及卸载释放旧上下文；标签、浮动图例、默认/模板 Tooltip 按层级排列并各导出一次。 |

模板内容为被动展示，图例滚动条和整行系列切换继续可用。模板优先于原文字/绘制回调；Build 返回 null 隐藏对应内容。标签 formatter 返回空文本时，模板仍能绑定原业务数据。模板异常在清理后传播，失败模板不会每次重绘反复构建；替换模板可以恢复。控件复用通过绑定更新 DataContext，Build 中固化的文字不会自动重建。

Demo 的 Charts 页新增“图例与数据标签：渠道卡、订单明细和长列表滚动”：16 个渠道、折线目标、散点观察、业务订单卡、模板开关、更新数据和重置视图。独立 [Usage AXAML](../samples/Charts.Usage/MainWindow.axaml) 展示 typed DataTemplate、原始业务对象、动态资源和 VM 开关；[接入说明](../src/NT.AvaloniaControl.Charts/README.md) 记录完整契约。

两平台 Release 编译零警告、零错误。40 项新增测试覆盖实际控件布局、原 Item/ID、NaN/视口裁剪、预算、正负柱、混合标签避让、资源/INPC/VM 替换、模板复用/释放、父控件与重入保护、真实滚轮和点击取消、导出单次子树。包消费者使用独立全新包缓存，没有源码项目引用；公共依赖归档按锁文件内容哈希和复制 SHA 核验，NuGet 审计与警告策略保持启用。

原生取样覆盖亮暗主题的业务编号、图例首项和滚动末项实际文字像素。首项中文文字用同一 TextBlock 隐藏、恢复的区域逐像素差验证：隐藏后变化至少 5 个像素，恢复后区域完全一致，并核对原文字、前景色、几何与视图不变。原容差 24 的近色计数完整保留为诊断。96/144/192 DPI 的固定 960×540 PNG 分别检查文字区域、像素内容一致性和 pHYs 元数据。留存的是原生窗口/图表的 RenderTargetBitmap 与导出 PNG；没有将它们标为桌面截图、物理输入或 compositor present 测量。

两平台使用同一份 **1201 文件冻结副本、532 个声明验证输入**，最终与 live 的声明输入逐项核对；后增的总览/验证文档不作为运行时源码变化。Core/Themes 公开类型仍为 **69/3**，新增 11 个成员，已有公开类型/成员声明无删除或签名变化；[本批 API](charts-c2-control-templates-api.txt) 与平台 API 声明独立核对。C0 冻结文件、官方矩阵 200 个 ID/顺序及 54 个来源不变。

完整文件路径、SHA、程序集、环境、命令与原始结果见 [验证清单](charts-c2-control-templates-validation.json)；证据保存在 [本批运行目录](../artifacts/charts-c2-control-templates-20261016)。基础运行显式跳过内嵌包消费者，另一个独立脚本执行两类真实包消费者，总清单分别引用两份结果。

此前失败均保留：Windows 首轮消费者图表处于窗口外，后续先 BringIntoView，并以真实滚轮 Source/Handled、可见坐标、偏移、末项原身份和取消为门禁；独立 InputHitTest 的不同结果保留为诊断，未据此判断框架缺陷。Linux 前两轮均有亮色图例首项近色计数 0，其余 159 项通过；第二轮等待 80ms 仍未改变结果。精确初始 PNG 中中文文字可见，最近 RGB 通道差为 26，超出纯色检查的 24；最终采用上述实际文字的隐藏/恢复对照，并保留近色 0 与失败记录。80ms 仅用于验证窗口准备，不计作控件首次可用性能数据。API 初版解析器漏识别两种生成类型的记录和修正后完整差异也都保留。
