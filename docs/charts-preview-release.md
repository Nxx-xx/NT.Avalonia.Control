# Charts 首版预览发布收尾

冻结日期：2026-10-27。候选版本：0.2.0-preview.3。

本轮准备可私有试用的预览包，保留现有功能，冻结新增功能。官方功能对照按用户决定移出首版验收；官方性能对照、散点深度优化和SDK扩展后置。原性能门禁和历史失败保留，首版发布清单与原完整C7里程碑分别判断。

## 发布范围

- Core、Themes和可选Skia三个包；.NET 10、SDK10.0.402、Avalonia12.0.3。Skia适配包保持精确版本约束。
- Windows x64作为首版主要交付环境；Linux x64按实际WSLg/X11软件验证记录预览支持。未取得Ubuntu22.04/24.04实机、硬件GPU、物理触控和ARM64认证。
- 普通JIT和依赖运行时的目录部署。单文件、裁剪、NativeAOT及其他部署方式不列入本版承诺。
- 保留既有图族、绑定、主题、选择、缩放平移、Tooltip/Trackball和导出；高级专业布局及完整官方等价继续跟踪。
- 散点保留，高密度高频刷新尚未满足原固定负载目标。本版不承诺官方性能等价、真实60FPS或百万点实时交互。

## 发布前检查

1. 冻结源码、范围文件、依赖、版本和数据/运行参数。
2. Windows/Linux分别锁定还原、审计、构建及打包，检查包内程序集、依赖和README。
3. 新隔离缓存消费实际nupkg，无源码项目引用；验证Core、Themes、Skia三种原生接入及完整既有绑定消费者。
4. 正常启动、多语文字、原始数据命中、PNG/JPEG、取消与失败恢复；出现阻断缺陷先修复，再冻结新候选，保留旧失败。
5. 每平台100轮生命周期和8小时长稳，串行运行。原始资源序列、进程身份和失败证据完整保留，不强制GC或周期清缓存来改善曲线。
6. 补齐接入、已知限制、API/主题快照和版本说明；生成发布物清单与校验和。

机器范围见[冻结范围](charts-preview-release-scope.json)。实际验证状态由独立结果文件记录；尚未运行的检查不预填通过。

## 分发状态

当前仅准备本地/私有试用包，不执行远程推送。项目自身的分发许可尚待确定；已有第三方声明不代替项目许可。公开发布准备状态必须同时反映许可、验收和实际产物，不能因成功打包而登记为已发布。

## 长稳后收尾

现有串行长稳保持原协议和原门槛。`Start-ChartsPreviewCloseout.ps1` 可等待该长稳进程退出，再重新核对候选源码、全部验收记录和交付文件。只有两端完整8小时独立判定通过，才会登记为私有试用就绪，并生成本地ZIP及SHA256；归档内每个文件还会与交付目录逐字节核对。失败保留原始证据，不覆盖为通过，也不执行远程发布。

交付目录同时保存 `validation.json` 和同内容的 `charts-preview-release-validation.json`，使仓库和离线交付中的验收链接均可使用。接入步骤见[本地包接入](charts-preview-quickstart.md)。

2026-10-28补查：修复离线验收链接，增加便携交付核验器和本地包接入步骤。候选的295个当前产品输入与冻结源码一致，Windows完整长稳独立判定通过。交付核验器9项测试、长稳判定器13项测试通过，覆盖包损坏、缺失文件/链接、未跑满或内存超线不能登记通过等情况。首个收尾辅助进程因跨会话PID不可见退出，其失败回执保留；后续使用原监督进程心跳和最终写入回执判断，未重启或改变现有长稳。
