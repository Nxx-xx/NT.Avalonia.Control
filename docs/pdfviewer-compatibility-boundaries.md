更新：2026-10-15。本文记录当前后端和 P0 实测范围，最终产品仍按[开发计划](pdfviewer-development-plan.md)及[官方对照](pdfviewer-official-alignment.md)验收。[本轮验证](pdfviewer-p0-validation.md#真实出版语料与兼容性边界续轮)包含冻结构建与独立证据。

37 项操作包含 6 次编辑会话打开检查，合计 26 接受、11 拒绝，另有 6 项读取成功。会话打开只证明满足未加密 / 未签名等入口约束，不代表所有编辑功能可用。每项拒绝检查异常类型 / 原因及字节、Revision、Dirty 不变。非 GNU 的小区域删除在清理预检已停止，下游局部删除没有执行。它们是有效出版 PDF，实现边界不代表源文件损坏。

IRS / 日本的 `Unsupported painting operator 'Dictionary'.` 来自 PDFsharp 对有效 BDC 内联属性字典的解析表示，PDF 没有 Dictionary 绘制运算符。NIST 实际图像过滤器是 JBIG2 / JPX，不能因通用异常消息提及 JPEG 就登记为 JPEG 实测。

PDFium 读取与 FreeText 渲染抽样首 / 中页，并未渲染全部 314 页。独立解析检查 FreeText 重写前后所有页面原正文流与原内嵌字体，Poppler 比较代表页批注区域外像素。GNU 删除另检查目标页无绘制内容，其余 228 页绘制操作 / 文本保持及中 / 末页像素。初始 6 份样本不构成任意 PDF 或统计兼容率承诺。

## 能力范围

| 能力 | 当前支持或实测 | 拒绝 / 未覆盖 |
| --- | --- | --- |
| 阅读 | 提供加载、文字、目录、搜索、渲染；本轮验证真实样本加载、代表页文字 / 渲染及目录读取，搜索沿用历史测试 | 本轮未新增真实语料搜索验证；提取顺序取决于文字层；不提供 OCR |
| 原样保存 | 未编辑会话字节快照和流保存 | 不能推断结构重写、签名编辑或任意保存兼容 |
| FreeText 写入 | 未加密 / 未签名、受尺寸限制；显式静态 glyf TrueType，Auto / Full / NoSubsetting；水平单行，已验证 CJK 标量映射 | 新字体 CFF / TTC / 可变字体、缺字、复杂排版 / RTL / 竖排及编辑 UI 尚未完成 |
| 源字体保留 | 样本既有 CFF / CID / Type1 等资源在本轮 FreeText 重写中保留 | 不等于允许这些格式新增字体或编辑原文 |
| 既有表单保留 | IRS 各 48 末级字段、48 Widget 的值 / 标志 / AP 全状态、XFA 包保留 | 不等于生产填写、XFA 交互、JavaScript / 提交 / 校验支持 |
| AcroForm 原型 | 历史字段 / 两轮输入保存 / CJK AP 桥已有证据 | 生产焦点 / 虚拟化 / 定时器、IME、编辑字体 / 光标及任意样式归 P6 / P9 |
| 严格清理 | RemoveAllNonPageData 完整新目录重写；GNU 通过 | 会删除全部批注 / 表单 / 附件 / 目录等；颜色空间、压缩图像、透明 / 裁剪等仍有限制 |
| 整对象删除 | 公共 API 删除完全覆盖的承诺对象，修剪资源后严格清理；GNU 整页内容通过 | 部分对象、受影响旋转页及不支持绘制路径明确拒绝；通用 UI 未完成 |
| 部分文字 / 图像删除 | 历史独立原型验证 CJK 簇、坐标、无损 RGB / 灰度像素及共享实例隔离 | 无生产 API；通用编码 / TJ / 排版 / JPEG / 遮罩 / 裁剪 / Form 等归 P7 |

TJ 可由阅读后端处理，严格清理也允许合法 TJ，GNU 清理实测包含 TJ；仅历史字符簇原型尚不解析 TJ。NIST 文字来自已有不可见 OCR 层，不保证准确，不代表新增 OCR。FreeText 重写可能规范化对象并更新 Info / Producer；本轮核验明确语义和像素保留，不声称任意结构字节无损。

## 阶段归属

P0 四类可行性及初始真实语料边界已有技术证据。官方可运行参考版本、Ubuntu / 麒麟精确镜像与参考设备入口仍为外部待办，G0 开放；P1 可推进契约、调度生命周期及 Ubuntu 原生 / CI。

事务 / Undo 归 P4，完整批注 / 字体互操作归 P5，表单宿主 / IME 归 P6，生产部分删除 / 绘制兼容归 P7，打印归 P8；规模语料、UI / 峰值 / 官方性能、目标平台终验归 P3 / P9。迁移不删减最终要求。本轮 Windows 后端结果不能代替 Linux / 麒麟实机、物理输入、外部编辑器或官方性能结论。
