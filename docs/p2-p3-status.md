共享原则：保留P1节点/列身份及源路径与视图索引分离；API优先增量扩展；源操作和业务规则属于功能侧，主题只组合视觉；滚动位置使用节点身份，不能由旧行号推断。P1的公开API快照已保存在 `validation/p1-public-api.txt`，当前API快照在集成审查后更新。

集成重点：

- 十万行与百列：行、单元格和列头数量由视口及冻结区约束，滚动复用。
- 展开/折叠/插入/删除：路径、可见行、命中及滚动锚点一致。
- 前事件加载数据或移除目标：不在回收的旧容器或失效节点上继续操作。
- 选择/编辑基础状态在树变化后仍遵守隐藏保留选择、隐藏取消编辑等P1契约。
- 两个程序集配套打包，独立NuGet消费者编译XAML并运行，公共主题URI可用。

公共 API 已完成增量审查：P1 所有公开和受保护成员保持可用；原层级源与布局构造签名保留，新增树操作采用 virtual 实现，避免迫使现有自定义源实现新的 abstract 成员。路径展开使用 SetExpandedAt，避免与 SetExpanded(default, bool) 产生重载歧义。当前快照已更新，历史快照单独保留。

集成审阅补充四项回调边界回归：行高回调替换 Source 后不能发布旧几何；清空列后列头可先于行重新测量；ValueGetter 在清理容器后不能回写旧值；同步绑定初始化期间撤列必须释放返回的订阅。这四项 Debug 回归已通过。
