# Charts C4-02：可见数据裁剪

执行完成日期：2026-10-19（批次于 2026-10-18 开始，证据目录日期保留批次标识）。最终候选 `c4-visible-clipping-source-v1` 已通过 Windows 与 Ubuntu 26.04 WSL2/WSLg 软件验证。下一项为 C4-03 保真抽样和层级细节。当前验证范围为 CartesianChart 稳定内置投影与内置系列的几何、保留绘图和矩形选择；小线形/空间画刷/未知投影等保守分支见下，完整 C4 性能、长期内存和物理平台门槛仍开放。

## 实现与原始数据语义

- 可见候选以不可变坐标版本为键缓存：有序升/降 X 用二分范围，窄 Y 或非有序/二维点及相邻线段使用按需空间树；查询返回原物理序号，不创建缩减版数据快照。完整覆盖、无法证明的反投影/极端饱和域保守保留候选，实际前向投影和绘图裁剪仍决定最终结果。
- 折线候选保留跨越视口的相邻线段两端及必要物理邻点，空点与不连续序号断开，不把两个被裁剪后的孤立片段连接。平滑曲线保留切线所需邻点，阶梯及面积/范围带保留对应边与填充覆盖；带状系列只按 X 排除，避免上下边均在 Y 视口外时误删填充。
- 在既有 renderer 最终可见性规则内，普通/分组/横向柱、范围柱、瀑布、方差、Pareto、散点/气泡/散点连线和 Pictorial 的内置绘制按覆盖范围扩张候选；标记的形状、描边、最大编码尺寸、组内偏移与柱状零基线的跨界覆盖保留。编码点最大直径按不可变样式快照首次汇总一次，随后只排序/保留可见 K 项，不每视口复制或排序整个源。
- Tooltip、点命中和选择仍从完整不可变快照按原始序号解析 Item、StableId、SourceIndex 和 RawPoint。矩形选择先对候选序号投影，再用原来的精确可见中心规则判断，保留分组偏移、数量上限、追加和可取消选择语义；零面积矩形仍遵循既有 Avalonia.Rect.Intersect 结果。Range RawPoint 继续使用既有映射的 max(High,Low) 点，原业务 Item 的字段完整保留，不把 ValuePath 中未采用的 Y 改成新的坐标契约。
- 视口重建保留坐标索引；源/映射/有效显示数据版本变动按原失效协议重建。Pareto 累计线的次数据快照按不可变主数据复用，类别排序接回同一累计快照，避免每个视口复制全量累计点。临时视图只持有当前几何/候选；移除数据和卸载仍可回收。
- 平滑堆叠以完整有效连续段拓扑决定共享厚度限制器分组，避免远处间隙被当前裁剪抹掉后错误合组；正常对齐组可裁剪，完整段相同但原始 X 拓扑不同/投影饱和的病理组保留全几何。拓扑摘要按数据/轴域/基线复用，单个数据最多保留8个域配置，FIFO 淘汰，配对比较使用弱引用缓存。
- 少于8192点的 legacy 线性折线保留直接全路径，维持既有实时几何 Bounds 契约并避免小场景索引开销。依赖完整路径 paint bounds 的非实色全局画刷（如线/带状/累计线渐变）保留完整几何；逐点/柱/符号原语仍可安全筛选。未知自定义轴/投影或不能证明安全的映射沿原保守实时路径，外部 renderer 的逐次调用契约不变。
- 新增内部工作计数仅用于诊断和回归，未新增公开裁剪模式或改变公开数据/命中 API。九个诊断场景覆盖百万点有序折线、10万局部乱序线、10万二维散点、大标记、重复 X/间隙、对数反向、多轴、平滑与范围带；稀疏夹具每次窄视口的投影/遍历量须非零且小于源规模1/4。
- 本批窄窗口夹具中点候选集合与独立源扫描一致；独立数学 oracle 还核对相邻有限线段 AABB 穿越所需端点的完整子集、原始序号有序唯一及哈希；真实命中/Tooltip/单点和矩形选择保留原身份。完整前后计数与源访问记录独立相减；此前 C4-01 的9个缓存场景也重新运行。
- 冷附着阶段单独记录源映射与首次索引工作；夹具在冷阶段前可能已有未附着配置触发的源枚举，前表明确记录，不声称端到端首次可用。索引建树、尺寸/拓扑摘要仍有首次全量成本。Headless 记录、计时和线程分配均为本机诊断，不等于 FPS、present 或正式尾延迟/内存 SLA。

## 剩余问题

- C4-03 保真抽样和层级细节为下一项；裁剪不是 LOD。大量点真实落在视口内或许多非有序线段同时跨越视口时，候选 K 仍可接近 N，投影、排序、命中/选择和重放仍有相应成本，没有所有场景 O(log N) 或 O(1) 绘制保证。
- 首次空间树构建、数据映射/极值、编码尺寸摘要、平滑堆叠拓扑及配对首次比较仍可能扫描全量；类别组距 LayoutCategoryGroups 为保持全局间距语义，当前每个新视口仍 Map/Distinct/排序完整类别源，尚未取得全部布局 O(visible) 资格。
- 少于8192点 legacy 线、依赖完整 paint bounds 的空间画刷、病理平滑堆叠和未知扩展采用保守全路径；更精细而等价的裁剪、完整扩展通知组合及独立 Circular/Polar/Gauge/Sparkline/Analysis 图族的裁剪仍待后续。
- 缓存字节预算、原生/GPU retained resources、异常中断资源回收、密集标签/模板、增量与实时调度、30分钟/8小时长期内存和吞吐资格仍归后续 C4；本批不将弱引用/8配置上限测试当作完整内存回归认证。
- 诊断时间与分配包括反射、绘图记录和独立核对，未评估正式帧率/延迟/字节预算；百万点 hit p95 历史回退 0.7649→1.1235 ms 按用户决定继续留 C4 后续优化。
