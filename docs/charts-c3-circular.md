## 功能与 Demo

`CircularChart` 与 `PieSeries`、`DonutSeries`、`SemiDonutSeries` 支持原始贡献占比、零/负值处理、起止角与方向、内外半径、扇区间隙、小扇区、外标签连线、原始项身份选择与当前帧过渡动画。Demo → Charts →「圆形图」包含六图与交互控制，Usage 编译绑定和两类隔离 NuGet 消费者同步接入。

## 实现契约

- CircularChart 是独立投影，PieSeries、DonutSeries、SemiDonutSeries 复用 ChartSeries 的数据映射、原始项身份与生命周期；每个可见系列独立归一化，多个系列可设置 Radius/InnerRadius 组成同心环。
- 默认仅映射快照中的有限正值创建扇区；零、非有限值和显式 IsEmpty 不分配角度。显式共享 EmptyPointMode 可先填充缺失值，填充后的贡献仍保留 WasEmpty 元数据。负值模式 Ignore 忽略、Absolute 使用绝对贡献但保留原始负值、Throw 明确拒绝有限负值。先除以最大贡献再进行补偿求和，避免 MaxValue 总和溢出并支持次正规数；不可表示的微小份额保持零，不制造最小假份额。
- 默认起点 -90°、顺时针 360°；SemiDonut 默认从 180° 顺时针走 180°，内半径为 0.6。StartAngle 接受有限角度并归一化，SweepAngle 为 0..360，Radius 为 0..1，InnerRadius 为 0..<1。部分圆按实际角度范围适配布局，半环使用可用高度。
- SliceGap 仅减少边界两侧绘制角度；MinimumSliceAngle 与 SmallSliceMode.Keep/Hide 决定小扇区保留或隐藏，均不合并、扩张、重新归一化原始占比。隐藏小扇区保留源身份和 Fraction，但不参与绘制、标签或选择。
- 完整单值饼和环使用两个半圆弧；完整环的内外轮廓方向相反且不增加径向描边接缝。命中按当前显示的填充扇区、内洞、角度间隙及分离中心计算，边界包含并仅作机器精度修正；重叠取后绘制项，退出扇区不可命中。描边外沿和透明度像素采样不扩展命中区。
- ColorPath 接受直接 Color、IBrush 或可解析颜色字符串；无效值回退系列 Fill 与类别调色板。SourceIndex、StableId、Item、Category 和原始数值不随角度布局、分离、选择或动画改写。
- GetSlices 返回当前场景；Data、Fraction、RawStartAngle/RawSweepAngle 在过渡期间指向目标业务贡献，StartAngle/SweepAngle、Center、InnerRadius/OuterRadius、Fill 和 Hit.Position 对应当前显示帧。退出项以 IsExiting 标识，完成后移除。
- 外标签按左右分组，按可用容量优先保留较大贡献，再沿锚点高度布局；无法放入的标签省略，换行压成单行并可截断。每个保留外标签有三点连线。内标签在弧长、环宽、画布或碰撞约束不满足时省略，不保证文字矩形逐像素包含于扇区内部。
- 中心文字与 unparented CenterContent 分别支持常规文本和控件；中心控件通过单独宿主裁剪到环洞内接方框与绘图区交集，超大内容保留自身尺寸并受宿主裁剪。无内洞时不显示中心内容，部分环不自动产生额外扇区。
- 点选择支持 None、Single、SingleDeselect、Multiple、双向 SelectedPoint/SelectedPoints、可取消前置事件、重入防护和按稳定身份更新/清除；选择分离与固定 ExplodedIndex 分离叠加。键盘支持左右、Home/End、Space/Enter 与 Escape，Tooltip 使用圆形图自身的 formatter。
- 入场、数据和视图变化支持时长、缓动、延迟、暂停、继续、取消、重播、ReduceMotion 和点数上限；角度、中心、半径与 solid 颜色/Opacity 按当前帧插值，非 solid brush 直接切到目标。移除项收拢退出且不再参与交互；取消和隐藏/卸载结算到最新目标。
- PNG/JPEG、同步/异步、尺寸、背景、DPI、预算、取消与失败事件通过共享导出管线提供；固定 PixelSize 保持相同像素外观，DPI 写入密度元数据。导出当前暂停帧及中心控件，真实原生像素与导出一致性由本批双平台探针验证。 中心控件采用同一 DrawingContext 的公共可视子树直绘，无中间位图或 VisualBrush 离屏面；按自身变换后的边界与裁剪区相交情况决定是否绘制；即使父项自身不绘制仍递归子项，行为对齐当前 Avalonia 12 捕获路径。
- IBrush 实例由调用方持有。solid 颜色插值依赖可用的前后帧；原地修改同一个可变 brush 不保证保留旧颜色，也不保证自动触发系列数据变化，应用可替换 brush 或显式更新数据。

## 剩余问题

- CircularChart 本批采用本库 API；官方许可运行时、完整官方属性/样式/行为与二进制兼容尚未认证。圆形图仍为系列级参数，未增加逐扇区独立圆角、半径、描边、分离集合和自定义可视模板等扩展。
- 圆形图的类别图例当前是绘制式单行展示，空间不足会截断后续项目；可交互图例、虚拟化、独立滚动及全部 Cartesian 标签/Tooltip 模板契约仍待后续适配。外标签容量不足时省略，不提供人工拖动或全局最优连线布局。
- 内标签采用弧长、环宽和画布/碰撞近似约束，文字矩形仍可能跨过内洞或外弧；与中心文字/中心控件的严格避让、完整扇区内包含和更高级布局仍开放，不能视为完整标签功能等价。
- CircularSeries 的共享数据底座不使 Cartesian 坐标轴、缩放平移、Trackball、范围选择、多图联动、标注或原生点级 automation 自动适用。圆形点级辅助语义与真实读屏器仍属于后续图族无障碍适配；本批未宣称完整 C2 功能等价。
- 中心控件导出覆盖公共可视子树的位置、变换/镜像、裁剪、透明度/遮罩、文本/绘制选项及稳定 Z 顺序；复杂 Effect、compositor 特殊 visual、分组透明度、平台材质/缓存和自定义绘制的完整等价仍待专项，不宣称任意可视效果均已认证。
- 圆形场景、动画、标签、选择查询与身份匹配的规模、分配、增量、内存、吞吐和尾延迟尚未建立 C4 性能资格；本批没有性能或百万点内存回归实测。
- C3-05 极坐标/雷达为下一项；C3-05～C3-07、C5/C6 其余图族和完整 C2/C3/C4/C7 仍开放。此前散点的专属大小图例/连续色标和 C6 无轴云/紧凑打包继续保留。
- 物理 Windows/Linux、实际 backend/GPU/compositor present、多屏 DPI、Ubuntu 22.04/24.04、原生 Wayland、ARM 和目标国产 Linux，以及真实保存对话框和读屏器工作流仍待独立验证。
- Windows UIA/Linux AT-SPI 原生选中集合枚举、Linux 嵌套点选择写入、点系统焦点及真实读屏器按用户决定保留到 A11Y-NATIVE-01；原失败门禁不改为通过，本批未重验。
